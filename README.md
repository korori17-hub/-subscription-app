# サブスク管理

スマートフォン向けの、サブスク（定額サービス）の金額と更新日を管理する Web アプリです。

- 円（JPY）と米ドル（USD）を登録できます。合計は設定した目安レート（初期値: 1米ドル＝159円）で円換算します。
- 更新日は空欄にでき、「更新日未確認」として末尾に表示されます。通知・カレンダー書き出しの対象外です。
- 合計の月額・年額がひと目で分かります（週額・年額・「◯日ごと」も換算して合計）。
- 次回更新日が近い順に並び、更新が近づいたものは目立つ色で表示されます。
- 更新日が過ぎると、次の更新日へ自動で繰り上がります。
- iPhone のカレンダーに書き出して、更新の何日前かに確実に知らせてもらえます。
- ホーム画面に追加すると、アプリのように使え、電波がなくても動きます。

## データの保存場所（大切）

- 入力したデータは **この端末のこのブラウザの中（localStorage）だけ** に保存されます。サーバーには一切送信されません。
- そのため、次の場合は **データが消えます**。
  - 機種変更したとき
  - Safari の「履歴と Web サイトデータを消去」をしたとき
  - 別のブラウザやホーム画面アプリ以外から開いたとき（保存場所が別になることがあります）
- 設定エリアの **「バックアップを書き出す」** で、ときどき JSON ファイルを保存しておいてください。「バックアップを読み込む」で復元できます。

## カード番号などは入力しないでください

このアプリは、カード番号・パスワード・ログイン情報を扱いません。
「支払い方法」には『クレカ（楽天）』『口座振替』のような **名前だけ** を入れてください（カード番号らしい数字は保存できないようにしています）。

## 開き方

### いちばん簡単: `index.html` を開く

フォルダ内の `index.html` をブラウザで開けば動きます。
ただしこの方法ではオフライン機能（Service Worker）と通知が働かないことがあります。

### 簡易サーバーで開く（パソコンで確認する場合）

```sh
cd subscription-app
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### GitHub Pages で公開する（iPhone で使う場合のおすすめ）

1. このフォルダの中身を GitHub のリポジトリに push します（`index.html` がリポジトリのルートにある状態）。
2. GitHub のリポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. Branch で **main**、フォルダは **/ (root)** を選んで **Save**。
5. 1〜2分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URLです。

※ 公開されるのはアプリのプログラムだけです。入力したデータは各自の端末内にしか保存されません。
※ アプリを更新したときは `sw.js` の `CACHE_VERSION` を上げると、利用者の端末にも新しい版が届きます。

## iPhone での使い方

### ホーム画面に追加

1. Safari で公開URLを開く
2. 画面下の **共有ボタン**（四角から矢印が出たマーク）をタップ
3. **「ホーム画面に追加」** を選ぶ

以後はホーム画面のアイコンから起動してください（データの保存場所もこちらになります）。

### カレンダーに書き出す（おすすめのリマインダー）

1. 各サブスクの「カレンダーへ」、または設定エリアの「すべてをカレンダーに書き出す」をタップ
2. ダウンロードされた `.ics` ファイルを開く（Safari のダウンロード一覧、または「ファイル」アプリから）
3. 「すべてを追加」または「カレンダーに追加」を選ぶ

更新日が繰り返しの終日予定として入り、「何日前に知らせますか」で決めた日数前の **朝9時** に通知されます。
金額や周期を変えたときは、カレンダーの古い予定を削除してから書き出し直してください。

### ブラウザ通知の制限

- 「通知を許可する」を押すと、アプリを開いたときに更新が近いサブスクを通知します（同じサブスクは1日1回まで）。
- iPhone では、**ホーム画面に追加したアプリから開いた場合のみ** 通知できることが多いです（iOS 16.4 以降）。
- アプリを閉じている間に知らせる機能はありません。確実に知らせてほしい場合はカレンダー書き出しを使ってください。

## デモデータについて

- 空の画面や設定エリアの「デモデータを入れる」で、使い方を試すための **架空のデータ** を入れられます。
- 名前はすべて「デモ：動画配信A」のように **「デモ：」で始まり**、金額も架空です。
- 入れたあとは普通のデータとして編集・削除できます。実際に使い始める前に削除してください。
- 最初から入っているデータはありません。

## ファイル構成

```
index.html              画面
manifest.webmanifest    ホーム画面追加用の設定（PWA）
sw.js                   オフライン対応（Service Worker）
css/styles.css          デザイン
js/dates.js             日付の計算（Asia/Tokyo の「今日」、月末・閏年の扱い）
js/subscriptions.js     データの検証・自動繰り上げ・月額/年額換算
js/storage.js           localStorage への保存、バックアップの書き出し/読み込み
js/calendar.js          カレンダー書き出し（.ics）
js/notifications.js     ブラウザ通知
js/ui.js                画面部品（ダイアログ・お知らせ表示など）
js/views.js             ホーム画面の表示
js/form.js              追加・編集フォーム
js/app.js               全体の制御・起動処理
icons/                  アプリアイコン
tests/selftest.js       計算ロジックの自己チェック（node tests/selftest.js）
```

外部ライブラリ・外部サーバーへの依存はありません。

## 開発者向けメモ

- 保存キー: `subkanri.v1`、形式は `{ "version": 1, "subscriptions": [...], "settings": { "usdJpyRate": 159 } }`。
- 日付はすべて `YYYY-MM-DD` の文字列で扱い、タイムゾーンによる日付ずれを避けています。
- 毎月31日など月末の契約は、本来の日（`anchorDay`）を覚えておき、2月は28/29日、翌月は31日に戻します。
- 自己チェック: `node tests/selftest.js`
